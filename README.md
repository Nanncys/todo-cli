# todo-cli
一个用 Python 写的命令行待办事项管理器。
存储上，使用json文件保存备忘录和待办列表，待办列表包括id，创建时间，待办截止时间，事件内容，是否完成，所属备忘录id
前端使用命令行直接输入输出的简单方式
功能有
0.创建一个备忘录
1.查看备忘录列表
2.删除一个备忘录
3.进入一个备忘录，查看其中的项目列表
4.添加项目
5.删除项目
6.将项目设定为已完成
7.一键清除已完成项目
